# Genshin Inspect — projeto de estudo

Recriação educacional inspirada na composição da imagem enviada, feita com HTML, CSS e JavaScript puro. Não contém o código-fonte original do site oficial nem reproduz seus arquivos proprietários.

## Como abrir no VS Code
1. Extraia a pasta `genshin inpect`.
2. Abra o VS Code.
3. Clique em **Arquivo > Abrir Pasta** e selecione `genshin inpect`.
4. Abra `index.html`. Para uma experiência melhor, use a extensão **Live Server** e clique em **Go Live**.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: layout, cores, responsividade e cenário ilustrativo feito em CSS.
- `script.js`: menu mobile, modal de apresentação e painel de redes sociais.

Os links de download/redes são demonstrativos. Antes de publicar, substitua-os por endereços oficiais e use apenas imagens/marcas que você tenha autorização para utilizar.


## Paisagem animada
A imagem de fundo fica em `assets/paisagem-teyvat.webp`. A animação faz um movimento lento de câmera/zoom para dar vida à paisagem. Para trocar a imagem, substitua esse arquivo mantendo o mesmo nome.
